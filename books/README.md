# Projets basés sur des livres

Chaque dossier rassemble les projets réalisés pendant la lecture d'un ouvrage. Il documente la référence bibliographique, les notions travaillées, les choix personnels et les différences éventuelles avec les exemples du livre.

Le code publié ici est une réalisation personnelle : il ne doit pas reproduire de longs extraits, illustrations ou fichiers protégés du livre.
