# Instructions pour les assistants IA

Avant de modifier ce dépôt, lire intégralement `documentation-ia/README.md`, puis les documents qu'il référence.

Le dossier `documentation-ia/` décrit l'objectif du portfolio, la fonction des principaux fichiers, les règles éditoriales et les vérifications attendues. Il appartient au dépôt source mais ne doit jamais être copié dans `site/` ni affiché dans la navigation publique.
